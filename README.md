# دَرْب | DARB — منصة تنسيق النقل الجامعي

> **مشوارك للجامعة، صار أوضح.**  
> منصة ويب متكاملة لتنسيق وإدارة النقل اليومي لطلبة الجامعات في **لواء الكورة ومحافظة إربد** (المملكة الأردنية الهاشمية).

---

## 📌 نبذة عن المشروع

مشروع **دَرْب (DARB)** هو منصة ويب حديثة مصممة خصيصاً لمعالجة تحديات التنقل اليومي لطلبة الجامعات الأردنية القاطنين في قرى وبلدات لواء الكورة (دير أبي سعيد، كفرالماء، تبنة، الأشرفية، كفرعوان، كفرراكب، سموع، جنين الصفا، جفين، وغيرها) والمتجهين نحو الجامعات الرئيسية في إقليم الشمال:
* **جامعة العلوم والتكنولوجيا الأردنية (تكنو)**
* **جامعة اليرموك**
* **جامعة جدارا**
* **جامعة إربد الأهلية**
* **جامعة آل البيت**

---

* **نظام التشغيل:** Windows 11 (أو macOS / Linux)

## 🚀 التثبيت والتشغيل المحلي (Quickstart)

### 1. تثبيت الحزم البرمجية
افتح موجه الأوامر أو الطرفية في مجلد المشروع ونفّذ:
```powershell
npm install
```

### 2. التشغيل على الجهاز المحلي (Local Development)
لتشغيل خادم التطوير محلياً:
```powershell
npm run dev
```
افتح المتصفح على الرابط:
👉 **[http://localhost:3000](http://localhost:3000)**

## 🌐 التشغيل على الشبكة المحلية (LAN / Wi-Fi Access)

تتيح المنصة إمكانية تصفح واختبار الموقع من أجهزة الهواتف الذكية أو أجهزة الكمبيوتر الأخرى المتصلة بنفس شبكة الـ Wi-Fi المنزلية أو المكتبية.

### الخطوة 1: تشغيل أمر الشبكة
```powershell
npm run dev:network
```
*(يقوم هذا الأمر بتشغيل خادم Next.js على الاستماع لكافة واجهات الشبكة `0.0.0.0:3000`)*

### الخطوة 2: معرفة عنوان IP لجهازك (IPv4)
في طرفية Windows، نفّذ الأمر التالي:
```powershell
ipconfig
```
ابحث عن سطر:
```text
IPv4 Address . . . . . . . . . . . : 192.168.1.XX
```

### الخطوة 3: الدخول من أي هاتف أو جهاز على نفس الشبكة
افتح المتصفح في هاتفك أو جهازك الآخر واكتب:
👉 **`http://192.168.1.XX:3000`** *(مع استبدال `192.168.1.XX` بعنوان IP الفعلي لجهازك)*.

> **ملاحظة أمان هامة:**  
> * `localhost:3000`: متاح للجهاز الحالي فقط.  
> * `IP:3000`: متاح للأجهزة المتصلة بنفس شبكة Wi-Fi فقط.  
> * الوصول عبر شبكة الإنترنت العامة يتطلب رفع الموقع إلى منصة استضافة سحابية (مثل Vercel). لا تقم بتعطيل جدار الحماية (Windows Firewall) بالكامل.

## 🧪 الوضع التجريبي (DEMO MODE)

تعمل منصة دَرْب بنظام **التبديل التلقائي إلى الوضع التجريبي (Automatic Demo Mode Fallback)**:
* في حال عدم تعيين متغيرات ربط Supabase، يعمل الموقع تلقائياً بنسبة 100% دون الحاجة لأي مفاتيح أو قواعد بيانات خارجية.
* يظهر في أعلى الموقع شريط بارز وأنيق:  
  **"وضع تجريبي — البيانات المعروضة لأغراض الاختبار فقط."**
* يتيح الشريط إمكانية التبديل السريع بضغطة زر بين 3 أدوار مختلفة للاختبار:
  1. **طالب جامعي (Student):** استعراض الخطوط، تقديم طلبات التنسيق، تتبع وإلغاء الطلبات، حفظ المسارات.
  2. **مزوّد نقل (Provider):** استعراض الحافلة المسجلة، مراجعة طلبات الطلبة وقبولها تجريبياً، فحص وثائق الاعتماد.
  3. **مشرف النظام (Admin):** إحصائيات المنصة، إدارة الخطوط، الجامعات، القرى، التقارير، وسجل التدقيق.
* جميع البيانات في هذا الوضع هي بيانات افتراضية للمحاكاة، ولا يتم تسيير مركبات حقيقية أو معالجة بطاقات بنكية أو دفع مالي.

## 🗄️ تهيئة قاعدة بيانات Supabase (اختياري للإنتاج)

عند الرغبة في ربط المنصة بقاعدة بيانات سحابية حقيقية:

1. انسخ ملف المتغيرات:
   ```powershell
   copy .env.example .env.local
   ```
2. ضع مفاتيح مشروعك من لوحة تحكم Supabase:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
   NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your-anon-publishable-key
   ```
3. طبّق ملف الهجرة والبيانات الأولية في محرر SQL بـ Supabase:
   * `supabase/migrations/20261007000001_initial_darb_schema.sql` (16 جدول مع سياسات RLS)
   * `supabase/seed.sql` (بيانات القرى والجامعات والخطوط التجريبية)

## 🛠️ الأوامر البرمجية المتاحة (Available Scripts)

|---|---|
| `npm run dev` | تشغيل خادم التطوير محلياً على `localhost:3000` |

| `npm test` | تشغيل حزمة الاختبارات الشاملة (Vitest) |
